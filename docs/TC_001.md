# TC_001 - Verify Textbox form submission with valid inputs

## Description
Verify that the Textbox form accepts valid inputs and displays the submitted details below the page after clicking Submit.

## Steps
1. Go to https://demoqa.com/forms
2. Click on 'Elements' from the left menu bar
3. Verify if the 'Textbox' menu item is present
4. Click on the 'Textbox' menu item
5. Enter Name in 'FullName'
6. Enter a valid email ID in the 'Email' textbox
7. Enter 'Current Address'
8. Enter 'Permanent Address'
9. Click on the 'Submit' button

## Expected Result
The submitted details should be displayed in the box below the page.
